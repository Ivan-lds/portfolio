# 👨‍💻 Portfólio Pessoal - Ivan Lima

## 📝 Descrição
Este é um site de portfólio pessoal desenvolvido com HTML e CSS para apresentar minhas habilidades, formação, projetos e informações de contato. O projeto foi criado para demonstrar minha experiência como desenvolvedor front-end e servir como vitrine para meus trabalhos.

## 🚀 Funcionalidades
- 📋 Apresentação pessoal e profissional
- 🛠️ Seção de habilidades técnicas
- 🎯 Exibição de hobbies e interesses
- 🎓 Formação acadêmica e cursos
- 💼 Portfólio de projetos com links para repositórios e deploys
- 📞 Formulário de contato
- 📱 Design responsivo para diferentes dispositivos
- 🔗 Links para redes sociais e currículo

## 🔧 Como utilizar
1. Clone este repositório ou faça o download dos arquivos
2. Abra o arquivo `index.html` em seu navegador
3. Navegue pelo site utilizando o menu de navegação
4. Explore as diferentes seções para conhecer mais sobre mim e meus projetos
5. Utilize o formulário de contato para enviar uma mensagem

## 💻 Tecnologias utilizadas
- HTML5
